# NoShortsThere!

Бесплатное расширение для Safari (macOS и iOS), которое убирает YouTube Shorts:

- полки Shorts на главной, в поиске и на страницах каналов;
- отдельные Shorts-ролики в выдаче поиска, подписках и рекомендациях справа от видео;
- пункт **Shorts** в боковом меню и вкладку Shorts на канале;
- нижнюю вкладку Shorts в мобильной версии (`m.youtube.com`).

Если Shorts всё-таки открыли по прямой ссылке, страница `/shorts/ID` перенаправляется на обычный плеер `/watch?v=ID`.

Расширение ничего не собирает и никуда не отправляет. Дополнительных разрешений нет: только content script на `*.youtube.com`.

## Как это работает

```
extension/                — само расширение (единственное место, где меняется логика)
├── manifest.json         — Manifest V3, content script на *.youtube.com
├── content.css           — простые CSS-правила: полки Shorts + класс скрытия
└── content.js            — MutationObserver: находит Shorts и прячет их карточки
xcode/NoShortsThere/      — Xcode-проект (обёртка-приложение для macOS и iOS),
                            ссылается на файлы из extension/
```

1. `content.css` подключается до отрисовки страницы и сразу прячет элементы, которые узнаются по тегу или атрибуту (полки Shorts, пункт мини-меню, вкладка канала).
2. `content.js` следит за DOM через `MutationObserver`. Найдя ссылку `a[href^="/shorts/"]`, он поднимается до карточки или полки и ставит на неё атрибут `data-nst-hidden`, а CSS её скрывает.
3. YouTube переиспользует DOM-элементы при прокрутке, поэтому скрипт следит и за сменой `href`: если в спрятанной карточке оказалось обычное видео, она снова появляется.

### Почему это не нагружает браузер

- **Без `:has()` в CSS.** Сложные селекторы браузер пересчитывает при каждом изменении страницы, а простые проверяются почти бесплатно.
- **Пакетная обработка.** Мутации копятся и обрабатываются один раз за кадр (`requestAnimationFrame`), а не на каждое изменение. Обработка идёт до отрисовки, поэтому Shorts не мелькают.
- **Сканируются только новые узлы**, а не вся страница. Если за кадр изменений очень много (первая загрузка), выполняется один нативный `querySelectorAll` по документу: это дешевле, чем обходить сотни поддеревьев.
- **`attributeFilter: ['href', 'is-shorts']`.** Остальные атрибуты, которые YouTube меняет постоянно, наблюдатель игнорирует.
- **В фоновых вкладках работы нет:** `requestAnimationFrame` там не вызывается, изменения копятся и обрабатываются одним проходом при возврате на вкладку.
- **Нет background-скрипта, таймеров и сетевых запросов.**

## Установка

### Что нужно

- macOS с Safari 15.4 или новее;
- **Xcode** из App Store (Command Line Tools недостаточно: в них нет `safari-web-extension-converter`);
- после установки Xcode выполни один раз:
  ```bash
  sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
  xcodebuild -runFirstLaunch   # иначе конвертер падает с «A required plugin failed to load»
  ```

### 1. Личные настройки сборки

В репозитории нет ничьих bundle ID и команд разработчика: в проекте стоит заглушка `com.example`. Свои значения задай в локальном файле, git его игнорирует:

```bash
cp local.env.example local.env
```

- `BUNDLE_ID_PREFIX` — префикс bundle ID, например `com.yourname`. Приложение получит `com.yourname.NoShortsThere`.
- `DEVELOPMENT_TEAM` — ID команды из Xcode → Settings → Accounts. Подойдёт бесплатный Personal Team с Apple ID. Если оставить поле пустым, сборка получит ad-hoc подпись, и в Safari придётся включать «Разрешить неподписанные расширения» после каждого перезапуска.

### 2. Собрать и установить

```bash
./scripts/build-macos.sh
```

Скрипт собирает Release-версию с настройками из `local.env`, устанавливает её в `/Applications` и запускает приложение. Запуск нужен, чтобы Safari зарегистрировал расширение. После установки скрипт удаляет папку сборки: иначе Safari показал бы второй NoShortsThere! в списке расширений.

Держи приложение в `/Applications`: из защищённых папок вроде Рабочего стола Safari может не подхватить расширение.

> **Не выбирай Team в Xcode-интерфейсе** (Signing & Capabilities): Xcode запишет ID команды прямо в `project.xcproj`, и он попадёт в коммит. Если это уже случилось, перед коммитом проверь `git diff` и убери строки `DEVELOPMENT_TEAM`.

### 3. Включить в Safari

1. Safari → Настройки → Расширения → включи **NoShortsThere Extension** и разреши доступ к `youtube.com`.
2. Только для сборки без команды: Safari → Настройки → Дополнения → **«Показывать функции для веб-разработчиков»**, затем вкладка **Разработчик** → **«Разрешить неподписанные расширения»**. Флаг сбрасывается при каждом перезапуске Safari.

### iPhone / iPad

Для iOS готового скрипта пока нет. Открой проект в Xcode и выбери схему **NoShortsThere (iOS)**. Выбери Team в Signing & Capabilities, но **не коммить** это изменение: смотри предупреждение выше. Подключи устройство и нажми Run. Затем на устройстве: Настройки → Приложения → Safari → Расширения → NoShortsThere! → включить и разрешить youtube.com.

С бесплатным Apple ID сборка на устройстве работает 7 дней, потом её нужно запустить из Xcode заново.

## Отладка

- **macOS:** открой YouTube, затем Разработка → Показать веб-инспектор. Скрытые элементы ищутся в консоли так:
  ```js
  document.querySelectorAll('[data-nst-hidden]')
  ```
- **iOS:** подключи устройство, на нём включи Настройки → Safari → Дополнения → Веб-инспектор, затем на Mac открой меню Разработка → *имя устройства*.
- После правок в `extension/` запусти `./scripts/build-macos.sh` и обнови страницу YouTube.

### Если YouTube поменял разметку

YouTube периодически переименовывает компоненты. Если Shorts снова появились:

1. Открой веб-инспектор и найди тег карточки или полки, внутри которой лежит Shorts.
2. Добавь его в `ITEMS` (одна карточка) или `SHELVES` (полка целиком) в `content.js`.
3. Если элемент узнаётся просто по тегу или атрибуту, без проверки содержимого, лучше добавить его в `content.css`.

## Ограничения

- Пункт меню находится по подписи `Shorts`. YouTube пишет её так на всех языках, но если подпись когда-нибудь переведут, правило перестанет работать.
- `grid-shelf-view-model` — общий компонент сетки. Если YouTube поставит в одну сетку Shorts и обычные видео, сетка скроется целиком.
- Расширение не трогает фильтр-чипс «Shorts» в поиске: это просто кнопка, сами ролики всё равно скрыты.

## Публикация

- **Для себя:** бесплатно, через Xcode, как описано выше.
- **Через App Store:** нужен Apple Developer Program ($99 в год), при этом расширение может распространяться бесплатно. В Xcode: Product → Archive → Distribute App.
- **Через GitHub:** выложить исходники, каждый собирает сам по этой инструкции.
