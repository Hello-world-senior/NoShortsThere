# NoShortsThere!

Бесплатное расширение для Safari (macOS и iOS), которое убирает YouTube Shorts.

## Возможности

- Скрывает полки Shorts на главной, в поиске и на страницах каналов.
- Скрывает отдельные Shorts в поиске, подписках и рекомендациях рядом с видео.
- Убирает пункт **Shorts** из бокового меню и вкладку Shorts на странице канала.
- Убирает нижнюю вкладку Shorts в мобильной версии (`m.youtube.com`).
- Перенаправляет прямые ссылки `/shorts/ID` на обычный плеер `/watch?v=ID`.

**Конфиденциальность:** расширение не собирает данные и не отправляет сетевых запросов. Единственное разрешение — content script на `*.youtube.com`.

## Быстрый старт (macOS)

```bash
git clone git@github.com:Hello-world-senior/NoShortsThere-.git
cd NoShortsThere-
cp local.env.example local.env   # указать свои BUNDLE_ID_PREFIX и DEVELOPMENT_TEAM
./scripts/build-macos.sh
```

Затем включите расширение в Safari (см. [Включение в Safari](#3-включение-в-safari)).

## Требования

- macOS с Safari 15.4 или новее.
- **Xcode** из App Store. Command Line Tools недостаточно: в них нет `safari-web-extension-converter`.
- После первой установки Xcode выполните:
  ```bash
  sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
  xcodebuild -runFirstLaunch
  ```
  Без `-runFirstLaunch` конвертер завершается ошибкой «A required plugin failed to load».

## Установка

### 1. Настройки сборки

В репозитории не хранятся персональные bundle ID и ID команд разработчика: в проекте указана заглушка `com.example`. Собственные значения задаются в локальном файле `local.env`, который исключён из git:

```bash
cp local.env.example local.env
```

| Параметр | Описание |
|---|---|
| `BUNDLE_ID_PREFIX` | Префикс bundle ID, например `com.yourname`. Приложение получит идентификатор `com.yourname.NoShortsThere`. |
| `DEVELOPMENT_TEAM` | ID команды из Xcode → Settings → Accounts. Подходит бесплатный Personal Team с Apple ID. Если оставить пустым, сборка будет подписана ad-hoc, и после каждого перезапуска Safari придётся заново разрешать неподписанные расширения. |

### 2. Сборка и установка

```bash
./scripts/build-macos.sh
```

Скрипт:
1. собирает Release-версию с параметрами из `local.env`;
2. устанавливает приложение в `/Applications`;
3. запускает его, чтобы Safari зарегистрировал расширение;
4. удаляет папку сборки, чтобы в списке расширений Safari не появилась вторая копия.

Приложение должно находиться в `/Applications`: из защищённых папок (например, Рабочего стола) Safari может не загрузить расширение.

> **Важно:** не выбирайте Team в интерфейсе Xcode (Signing & Capabilities). Xcode запишет ID команды прямо в файл проекта, и он попадёт в коммит. Если это произошло, перед коммитом проверьте `git diff` и удалите строки `DEVELOPMENT_TEAM`.

### 3. Включение в Safari

1. Safari → Настройки → Расширения → включить **NoShortsThere Extension** и разрешить доступ к `youtube.com`.
2. Только для сборки без команды разработчика: Safari → Настройки → Дополнения → **«Показывать функции для веб-разработчиков»**, затем меню **Разработка** → **«Разрешить неподписанные расширения»**. Этот флаг сбрасывается при каждом перезапуске Safari.

### iPhone и iPad

Скрипта сборки для iOS нет, установка выполняется через Xcode:

1. Откройте проект `xcode/NoShortsThere` и выберите схему **NoShortsThere (iOS)**.
2. В Signing & Capabilities выберите Team. Это изменение не нужно коммитить (см. предупреждение выше).
3. Подключите устройство и нажмите Run.
4. На устройстве: Настройки → Приложения → Safari → Расширения → NoShortsThere! → включить и разрешить доступ к `youtube.com`.

При бесплатном Apple ID установленная сборка работает 7 дней, после чего её нужно снова запустить из Xcode.

## Как это работает

```
extension/                — расширение; вся логика находится здесь
├── manifest.json         — Manifest V3, content script на *.youtube.com
├── content.css           — CSS-правила: полки Shorts и класс скрытия
└── content.js            — MutationObserver: находит Shorts и скрывает их карточки
xcode/NoShortsThere/      — Xcode-проект (приложение-обёртка для macOS и iOS),
                            использует файлы из extension/
scripts/build-macos.sh    — сборка и установка для macOS
```

1. `content.css` подключается до отрисовки страницы и сразу скрывает элементы, которые распознаются по тегу или атрибуту (полки Shorts, пункт мини-меню, вкладка канала).
2. `content.js` отслеживает изменения DOM через `MutationObserver`. Найдя ссылку `a[href^="/shorts/"]`, он находит родительскую карточку или полку и ставит на неё атрибут `data-nst-hidden`, по которому CSS скрывает элемент.
3. YouTube переиспользует DOM-элементы при прокрутке, поэтому скрипт отслеживает и смену `href`: если в скрытой карточке оказывается обычное видео, карточка снова отображается.

### Производительность

- **Без `:has()` в CSS.** Сложные селекторы пересчитываются при каждом изменении страницы, простые проверяются почти бесплатно.
- **Пакетная обработка.** Изменения накапливаются и обрабатываются один раз за кадр (`requestAnimationFrame`) до отрисовки, поэтому Shorts не мелькают на экране.
- **Только новые узлы.** Сканируются добавленные элементы, а не вся страница. При большом объёме изменений (первая загрузка) выполняется один нативный `querySelectorAll` по документу.
- **`attributeFilter: ['href', 'is-shorts']`.** Прочие атрибуты, которые YouTube постоянно меняет, игнорируются.
- **Фоновые вкладки не нагружаются.** `requestAnimationFrame` в них не срабатывает, изменения обрабатываются одним проходом при возврате на вкладку.
- **Нет background-скрипта, таймеров и сетевых запросов.**

## Разработка и отладка

- **macOS:** откройте YouTube, затем Разработка → Показать веб-инспектор. Скрытые элементы можно найти в консоли:
  ```js
  document.querySelectorAll('[data-nst-hidden]')
  ```
- **iOS:** на устройстве включите Настройки → Safari → Дополнения → Веб-инспектор, подключите его к Mac и откройте меню Разработка → *имя устройства*.
- После изменений в `extension/` запустите `./scripts/build-macos.sh` и обновите страницу YouTube.

### Если Shorts снова появились

YouTube периодически переименовывает компоненты страницы. Чтобы обновить правила:

1. В веб-инспекторе найдите тег карточки или полки, в которой находится Shorts.
2. Добавьте его в `ITEMS` (отдельная карточка) или `SHELVES` (полка целиком) в `content.js`.
3. Если элемент распознаётся только по тегу или атрибуту, без проверки содержимого, правило лучше добавить в `content.css`.

## Известные ограничения

- Пункт меню определяется по подписи `Shorts`. Сейчас она одинакова во всех языках интерфейса; если её локализуют, правило перестанет работать.
- `grid-shelf-view-model` — общий компонент сетки. Если YouTube поместит в одну сетку Shorts и обычные видео, скроется вся сетка.
- Фильтр «Shorts» в поиске не удаляется: это только кнопка, сами ролики в выдаче скрыты.
